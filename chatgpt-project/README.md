# ChatGPT Project Setup

Use this folder to create a dedicated ChatGPT Project for BlueGreen Guide.

## What to Copy Into Project Instructions

Copy the full contents of:

```text
project-instructions.md
```

into the ChatGPT Project instructions field.

## What to Upload as Project Source Files

Upload these Markdown files as source files:

- `source-files/01-product-context.md`
- `source-files/02-phase-roadmap.md`
- `source-files/03-data-model.md`
- `source-files/04-brand-and-tone.md`
- `source-files/05-development-workflow.md`

## Optional Reference

Keep `prompt-starters.md` for yourself as reusable prompts when you want to move the project forward.
