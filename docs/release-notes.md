# BlueGreen Guide v1.0 Release Notes

**Release name:** BlueGreen Guide v1.0  
**Tag:** `v1.0.0`  
**Release type:** Phase 1 curated launch map proof of concept

## Summary

BlueGreen Guide v1.0 establishes the first public proof of concept for a calm, practical, map-first outdoor discovery app focused on paddleboarding and kayaking launch points.

## Highlights

- Interactive Leaflet/OpenStreetMap launch map
- Curated launch-point collection
- Search across launch names, regions, tags, activities, and descriptions
- Filters for region, skill, activity, and maximum difficulty
- Launch cards with practical summary information
- Launch detail panel
- Verification and source fields
- Responsive mobile layout
- Documentation site
- Field Guide & User Manual
- Quick Start guide
- FAQ
- Screenshot placeholder system

## Scope note

This release intentionally keeps the dataset curated rather than nationwide. The goal is to prove the product experience and data model before scaling to larger regions.

## Not included yet

- Live weather
- Wind
- Tides
- Water temperature
- Accounts
- Favorites
- Reviews
- User-submitted photos
- Suggested edits
- AI recommendations

## Suggested GitHub release description

```text
BlueGreen Guide v1.0 is the first curated launch-map proof of concept.

This release includes an interactive map, curated launch points, search, filters, launch cards, detail views, verification/source fields, responsive layout improvements, and a documentation package with a Field Guide & User Manual.

This is intentionally scoped as a curated proof of concept rather than a nationwide launch database. The next major work should focus on Phase 2 place detail pages and richer verification fields.
```
