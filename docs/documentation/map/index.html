Using the map

The map is BlueGreen Guide’s central discovery tool. Use it to move through an area, select places, and narrow the current results to what is visible.

Move around the map

Drag to pan and use the zoom controls to change the area you are viewing. Select a marker to see the place name and open its details.

Reset or narrow the view

Use Fit all places to return to the full result set. When you want to focus on the current area, show only places inside the visible map bounds.
