Curated collections

Collections provide a quick starting point for common planning needs without requiring you to build a filter combination from scratch.

How collections work

Selecting a collection filters the map and current result list to the places intentionally included in that collection. Clear the collection to return to the broader launch map.

Current examples

Phase 1 includes curated groupings such as Beginner Favorites, Family Friendly, Calm Water, Harbor Paddles, and Scenic Views.

Curated means intentional. Collections use explicit place IDs rather than automatically inferring membership from a single tag or score.
