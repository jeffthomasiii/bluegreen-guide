v1.2 highlights

Mobile

Field-ready navigation

Explore, Map, and Nearby navigation; compact map tools; responsive filter wrapping; and touch-oriented mobile sheets.

PWA

Installable app shell

Progressive Web App metadata and a versioned service-worker app shell improve repeat field use without implying full offline maps or offline external data.

Place model

Beyond launch-only data

The base dataset is now generalized to places, with blue, green, and mixed environment semantics and Water/Land discovery.

Field test

Small green/mixed pilot

Ten pilot records test parks, reserves, gardens, and mixed destinations. Diamond Valley Lake overlays an existing stable-ID record, so the pilot adds nine net-new runtime places.

Paddling

Launch Suitability Profile

SUP Suitability, Wind Sensitivity, Typical Use, Crowd Sensitivity, Staging Space, and Assessment Confidence provide curated comparison guidance for paddle-relevant places.

Access

Branded testing routes

The custom domain and branded alpha/testing entry routes provide public testers a cleaner path into the proof of concept.

Current scope: v1.2 is maintenance and validation work. It does not reopen Phase 1 or start the larger Phase 2 structured-place-detail expansion.

Historical: v1.1.0 Phase 1 closeout

v1.1.0 closed Phase 1 as a coherent map-first proof of concept with 56 canonical launch records at that point in development, final Design System 2.0 branding, source-aware planning information, public documentation, and lightweight validation.

Discovery

Leaflet/OpenStreetMap launch discovery with search, filters, five curated collections, map-bounds filtering, geolocation, cards, and responsive details.

Trust and clarity

Official source links, review metadata, verification labels, representative-image notices, and safety-aware wording.

Maintainability

Canonical data, generated browser data, collection configuration, public documentation, and repository validation were synchronized for the Phase 1 closeout.

Historical count: The 56-place number belongs to the v1.1.0 release record. It should not be read as the current runtime total.

Still not included

Live conditions

Weather, wind, tides, water temperature, water quality, trail status, and changing advisories are not integrated as a live-data layer.

Personal accounts

Accounts, cloud-synced saved places, favorites, and personal trip notes remain outside the current build.

Community content

Ratings, reviews, user photos, and suggested edits remain future work.

AI recommendations

Natural-language recommendations and automated trip planning belong to a later phase.

Planning, not a safety guarantee: An official source link does not verify every field. Confirm current access, rules, fees, closures, weather, wind, tides, water quality, trail status, fire restrictions, vessel traffic, and hazards before going.
