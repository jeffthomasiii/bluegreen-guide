# Changelog

## v1.0.0 - Phase 1 Curated Launch Map

### Added

- Interactive map-based launch discovery experience
- Curated launch-point collection
- Search and filter controls
- Launch result cards
- Launch detail panel
- Verification/source fields
- Mobile-friendly layout
- Documentation landing page
- Field Guide & User Manual
- Quick Start guide
- FAQ
- Screenshot placeholder assets and replacement checklist

### Notes

This release intentionally favors a smaller curated dataset over broad coverage. Future releases should expand data only as verification, source tracking, and detail quality can be maintained.
